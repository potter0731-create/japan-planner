# 일본 여행 플래너

생각나는 대로 적으면 일정·항공·숙소·예산·준비물로 알아서 정리해 주는 일본 여행 계획 페이지입니다.

- **자유 입력**: “12/16~19 오사카 2명”, “가는 편 KE723 12/16 09:00 인천 → 10:50 간사이”, “숙소 난바 3박 45000엔”, “오후 3시 기요미즈데라 500엔”처럼 적으면 정리돼요. 나눠서 여러 번 적어도 이어서 반영되고, “기요미즈데라 4시로”, “도톤보리 빼기”로 고칠 수 있어요.
- **일정 타임라인**: 장소 사이 이동 시간(거리 기반 추정), 구글맵 길찾기, 하루 경로 링크
- **지도**: 하루 동선을 숙소 → 방문지 순서로 선과 번호로 표시
- **예산·준비물·여행 팁**, 카드 조합 계산기(`cards.html`)

빌드 없이 정적 파일로 동작합니다. 입력한 내용은 브라우저(localStorage)에만 저장됩니다.
